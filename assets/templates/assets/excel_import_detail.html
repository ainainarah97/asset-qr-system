DA6 Processing

The DA6 workbook is processed according to the Premise and DAK asset hierarchy.

1. Premise / DPA
The DPA Number is used to identify the Premise. An existing Premise is reused; otherwise, a new Premise is created.
2. DAK Blok
New Blocks are created. Existing Blocks under the same Premise are skipped and are not overwritten.
3. DAKRuang
Existing Levels are reused. New Levels and Rooms are created. Existing Rooms are skipped without changing their stored information.
4. DAKKomponen
New Asset Components are created and linked to their Rooms. Existing Component IDs are skipped and are never overwritten.
